# Job Board Platform - MERN Stack

Plateforme de recrutement full-stack connectant candidats et recruteurs.

## 🛠️ Stack
- React + Tailwind CSS
- Node.js + Express
- MongoDB
- JWT pour l'authentification

## ✨ Fonctionnalités
- Authentification (3 rôles : candidat / recruteur / admin)
- CRUD offres d'emploi et candidatures
- Upload de CV (Cloudinary)
- Recherche et filtres avancés
- Programmation d'entretiens (date, lieu, notes)
- Dashboard recruteur et candidat

## 🚀 Installation

```bash
# Backend
cd backend
npm install
node server.js

# Frontend
cd frontend
npm install
npm run dev
